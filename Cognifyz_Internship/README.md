# Cognifyz Data Science Internship
Three independent folders - each has its own script, dataset and requirements:

  Level_1/  level1.py  -> Data exploration, descriptive analysis, geospatial analysis
  Level_2/  level2.py  -> Table booking & delivery, price range, feature engineering
  Level_3/  level3.py  -> Predictive modeling, cuisine preferences, data visualization

Run (inside a level folder):
  pip install -r requirements.txt
  python levelN.py        (N = 1, 2 or 3)

Cognifyz_Report.pdf = written summary of all results.
